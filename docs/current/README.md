## Working direction

The immediate goal is not maximum content. It is a small playable proof whose combat and visual presentation are strong enough that the owner can decide: “Continue in exactly this direction.”

Children of Morta is the primary quality reference for spatial pixel-art depth, grounding, readable silhouettes, atmosphere and emotional character presence. It is not a source to copy. Every influence must be translated into the project’s own Soulfire Gothic identity.
