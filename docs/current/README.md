# Projektwissen — The Lost Soul of Fire

Dies ist der zentrale Einstieg für Produktwissen auf GitHub. Stand: 04.10.2026.

## Verbindlichkeit

1. Neuere datierte Beschlüsse im [Entscheidungslog](DECISION-LOG.md) vor älteren widersprechenden Aussagen.
2. [Spielregeln](GAME-RULES.md), Produktidentität, Canon und thematische Dateien hier beschreiben die geltende Richtung.
3. Die [Konzeptaufnahme](RECORDING-SUMMARY-2026-09-08.md) ist eine Quelle mit Vorrang vor älteren widersprechenden Planungen; neuere Beschlüsse bleiben vorrangig.
4. `docs/mvp/`, `docs/vision/` und die Aufnahmeplanung unter `docs/planning/recording-2026-09-08/` enthalten historische Fassungen. Aussagen wie „locked“ ersetzen keine neuere Entscheidung.

Implementiertes Verhalten wird separat in `openspec/specs/` und am Code auf `main` geprüft. Systeme des Referenzbranches `prototype/design-polish` sind nicht automatisch auf `main` vorhanden.
