# Resonance / Enhanced Death-Flame Mode

**DESIGN STATUS: LOCKED**

The final production name is not locked. "Resonance", "Death Resonance", "Requiem", "Soulflare", or similar may be considered later.

For implementation, use **Resonance**.

## Fantasy

When a Lost Soul is successfully released, the actual Soul leaves the world.

A small **Soul Residue** remains and resonates with the Player's Flame of Death.

Repeated releases increase Resonance until the Player can temporarily unleash a much stronger state.

The Player does not consume Souls.

## Gain

`Successful Soul Release → Soul Residue → Residue flies into Player Core → Resonance increases`

Suggested balance:

- approximately 5–8 normal releases to fill the meter

**TUNABLE**

Core weakpoint interactions may provide bonus Resonance.

## Meter

Use one simple Resonance meter.

No:

- combo multiplier
- secondary resource
- decay system
- sub-meter

unless required by a locked mechanic. They are not currently required.

## Ready State

When full:

- Core pulses strongly
- clear audio cue
- UI communicates readiness

Player activates manually with `R`.

## Activation

Target sequence:

1. `R`
2. ~0.1 s freeze
3. screen becomes almost black
4. Player Core turns near-white
5. violet Death Flame erupts
6. return to gameplay

Transformation should be roughly ~0.5 seconds, not a long cutscene.

Values are **TUNABLE**.

## Visual State

During Resonance:

- violet flame around silhouette
- near-white Core
- purple cracks/veins spreading from Core
- stronger coat/hair reaction
- more particles
- subtle movement afterimages
- Player silhouette remains readable

Avoid unreadable "purple soup."

## Mechanical Buffs

Resonance adds no new abilities.

It enhances the existing kit.

### Player
- noticeably faster movement
- noticeably greater mobility

Suggested movement increase: around +10% as a starting point.

**TUNABLE**

### Scythe
- more damage
- more range
- more knockback
- larger Death-Flame blade

### Ignition Dash
- longer distance
- lower cooldown
- larger trail

### Soul Cannon
- faster charge
- larger shot
- more damage

### Soul Sense
- automatically active
- no Soul Sense movement penalty

## Duration

Suggested:

- ~10 seconds

**TUNABLE**

Do not extend duration from kills in MVP.

## End

- flame retracts toward Core
- small violet pulse
- stats return to normal
- automatic Soul Sense ends unless the Player is manually holding Q

## Death During Resonance

Use normal Player death behavior.

No special revive or transformation-death system.

## Out of Scope

Do not add:

- new Resonance-only abilities
- kill extensions
- upgrade tree
- multiple Resonance tiers
- alternate transformations
