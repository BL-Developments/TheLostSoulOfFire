## Status Convention

- `DESIGN STATUS: LOCKED` — implementation must preserve the decision.
- `TUNABLE` — numeric/detail value may be adjusted for balance or feel.
- `PROTOTYPE FALLBACK` — acceptable temporary implementation when final assets/effects are unavailable.
