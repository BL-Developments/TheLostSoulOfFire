# Windows-Prototyp testen

Danke, dass du den Prototyp ausprobierst. Entpacke das vollständige ZIP in einen eigenen Ordner und starte TheLostSoulOfFire.exe. Eine separate Installation des .NET SDK oder der .NET-Laufzeit ist nicht vorgesehen. Windows kann bei nicht signierten Testversionen eine Sicherheitsabfrage anzeigen.

Die Buildversion und der Quellstand stehen in build-info.json. Das ist ein früher Entwicklungsstand; Darstellung, Balance und Inhalte können sich ändern.

## Steuerung

- Bewegung: WASD oder Pfeiltasten.
- Zielen: Maus.
- Angriff: linke Maustaste; zum Angriff gedrückt halten.
- Fähigkeiten: Z und X.
- Seelenkanone laden und abfeuern: rechte Maustaste gedrückt halten, zum Abfeuern loslassen.\n- Seelenkanone laden und abfeuern: rechte Maustaste gedrückt halten, zum Abfeuern loslassen.
- Fähigkeitsauswahl: C.
- Charaktermenü: Tab.
- Pause/Zurück: Escape; im Pausenmenü damit schließen oder über die Menüauswahl fortfahren.

Menüs zeigen die jeweils verfügbaren Tasten am unteren Rand. Eine angeschlossene Tastatur ist erforderlich.

## Bekannte Grenzen

Dies ist ein früher Windows-Prototyp. Änderungen und Fehler sind zu erwarten. Nicht vorhandene oder noch nicht fertige Inhalte bitte als solche melden; trage hier keine ungeprüften Fehler als bekannte Probleme ein.
