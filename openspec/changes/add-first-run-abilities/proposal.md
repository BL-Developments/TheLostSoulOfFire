# Add first run abilities

## Why
The six abilities selected in #79 need playable behavior before final balancing. Run Glut already exists in the arena.

## What changes
Add Second Wind, Piercing Shot, Retreat, Vortex, Revenge and Setup using provisional costs. Equip two distinct abilities through a frozen selection panel in the hub or arena intro/intermission. Cast with Z/X during arena combat. Show costs, readiness and resource failures. Integrate revenge and setup bonuses with both existing weapons. Add deterministic tests and a native visual test using an isolated profile.

## Scope
Solo arena implementation on main. No random three-offer draft (#16), local coop port, Ultimate, persistent skilltree or final balance. Prototype values are not product balance decisions. Existing prologue combat remains separate.
